# Student Management System (Python OOP)

A robust Python application built to efficiently manage student profiles, course enrollments, and academic performance. This project serves as a practical showcase of core "Object-Oriented Programming (OOP)" pillars implemented natively in Python.

##  Tech Stack & Key Concepts
* Language: Python 3.x
* Core Paradigm: Object-Oriented Programming (OOP)
* Python Features: Custom Classes, Dunder Methods (`__str__`), Control Flow

##  Architectural Highlights (OOP in Python)
* Encapsulation: Protects internal student data using private/protected attributes and manages them safely.
* Inheritance: Avoids code redundancy by sharing common traits (like name or ID) from a foundational parent class into specialized subclasses.
* Polymorphism: Overrides standard Python methods so that calling actions on different objects outputs uniquely formatted data dynamically.
* Abstraction: Keeps the main application interface clean by hiding complex grading algorithms and enrollment logic inside dedicated class methods.

## Features
* Complete management (Create, Read, Update, Delete) of Student and Course profiles.
* Automated grade tracking and validation logic.
* Clean, interactive terminal interface.
